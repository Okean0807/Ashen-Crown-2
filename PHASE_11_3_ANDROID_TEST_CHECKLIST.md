# ASHEN CROWN — PHASE 11.3: ANDROID PHYSICAL DEVICE TEST CHECKLIST

**Версия RC (предлагаемая):** `rc/phase-11.3-recovered-baseline` / `rc-phase-11.3-baseline-1`  
**Цель:** Финальная проверка владельцем на физическом Android-смартфоне (Gate E) после публикации Preview URL (например, GitHub → Vercel Preview Deployment).

---

## 1. Подготовка перед тестом

1. Открыть опубликованный публичный HTTPS URL в **Chrome на Android** (обычная вкладка, без прокси AI Studio) с параметром **`/?diag=1`**.
2. Убедиться, что страница открылась напрямую (`HTTP 200`, без редиректа на `aistudio.google.com` и без `HTTP 403`).
3. Зафиксировать значения в диагностической панели `Диагностика RC 11.3`:
   * `Renderer` (`WebGL (Three.js)` или `2D (Canvas fallback)`)
   * `WebGL` (`OK (WebGL2)` / `OK (WebGL1)` / `UNAVAILABLE`) и `GPU`
   * `FPS` (ms), `Экран`, `DPR`, `DC`, `Tri`, `Ошибки рендерера (0)`.
4. Убедиться, что кнопка `Начать кампанию` нажимается напрямую при открытой панели `?diag=1` (проверка фикса `DEF-11.3-01`).

---

## 3. Дополнительные наблюдения для Android

* Проверить скрытие/появление адресной строки Chrome (`100dvh`) — нижняя панель управления не должна обрезаться.
* Свернуть Chrome на 5–10 секунд и вернуться — убедиться, что WebGL-контекст не потерян (или при потере корректно срабатывает откат на `2D (Canvas fallback)`).
* Проверить, закрывается ли панель диагностики тапом по кнопке `Скрыть`.
